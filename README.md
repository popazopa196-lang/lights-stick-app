Lights Stick App [лайтс стик ап] это веб-приложение написанная исключительно через нейронные сети для использования на мероприятиях
это веб-приложение работает в рамках одного учебного подразделения и создано исключительно в развлекательных целях
для создания атмосферы во время мероприятия и ярких впечетлений
если программа зайдет студентам и/или другим людям - я заморочусь и продумаю работу за пределами учебных подразделений ргутис
